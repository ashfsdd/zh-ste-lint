# 场景路由详细模板

> 配套 `航空手册五条` 技能使用。此处放可直接粘贴的提示词模板，SKILL.md 只保留路由表。

---

## 模板 A｜信息段生成约束（S1/S3 用，贴在原提示词后）

```
【信息段写作约束】（只约束攻略讲解、步骤拆解、参数对比、大纲、周报等信息段；
 整活、梗、反转、情绪铺陈等人设段不受此约束，保留原有风格）
1. 信息段每个句子不超过 30 个字
2. 一个句子只讲一件事
3. 同一个概念从头到尾用同一个词，不要换着叫
4. 主动语态：谁去做、谁去确认要写清楚，不要用"被"字句藏主语
5. 不确定的地方直接说不确定，不要用"一般来说""建议咨询"糊过去
6. 不许为了短句砍掉主语、动词或关键信息——短的意思是挤掉废话，不是挤掉信息
```

## 模板 A'｜解说稿专用（S2 用，刻意放宽第 1 条）

```
【解说稿信息段约束】（只约束攻略讲解、步骤、参数对比等信息段；
 梗、反转、整活、情绪高潮段完全不受限，保留原有风格）
1. 一个句子只讲一件事（解说稿可到 40 字，但不得一句塞两件事）
2. 同一个 BOSS/技能/道具从头到尾用同一个叫法，列一张名称对照表给我确认
3. 主动语态：告诉观众"你先做什么"，不要写"建议先提升装备等级"这种无人称句
4. 不确定的机制直接说不确定，并标注"待实测"
```

## 模板 B｜成稿体检 linter（S5 用，回报最高）

```
下面是我的一段稿子。请按航空维修手册五条逐句体检，只输出问题句，不要重写全文：
1. 标出所有超过 30 字的句子，并给出拆法
2. 标出一句话里讲了两件以上事情的句子
3. 标出同一个东西被换了名字叫的地方（列成 原名→别名 对照表）
4. 标出主语被藏起来的句子（"被"字句、无人称句、"建议"句）
5. 标出用"一般来说/建议咨询/视情况而定"糊过去的地方
输出格式：序号 | 违规条目 | 原句 | 改法
最后给结论：问题句共几个，值不值得把模板 A 加进日常流程。
```

3. 主动语态：谁去做、谁去确认要写清楚

## 边界案例

| 案例 | 处理 | 原因 |
|---|---|---|
| 起一个爆款标题 | 全关 | 禁营销形容词 = 禁"炸裂""神级"，点击率归零 |
| 写前三秒钩子 | 全关 | 钩子靠悬念和夸张，一句一事会泄劲 |
| 解说稿整活段 | 全关 | 要的就是长句铺陈和情绪堆叠 |
| 解说稿攻略讲解段 | 开 A' | 观众要"扫一眼就知道下一步干什么" |
| 整理 BOSS 机制表 | 全开 | 纯信息，名词一致性价值最大 |
| 核实"这个机制是不是真的" | 开第 4+5 条 | 区分"确认的"和"推测的" |
| 写周报/直播大纲 | 全开 | 领导/自己看，越短越省精力 |
| 头脑风暴想整活点子 | 全关 | 需要跳跃，不需要纪律 |

## 与 deai-promax 叠加的标准顺序

```
第一步：五条（理顺信息）——拆长句、定名词、明主语、标不确定
第二步：deai-promax（去 AI 腔）——换词汇、打散句长方差、拆三段式、降破折号密度
```

反过来会返工：先去味的文本仍可能一句塞三件事，还得再拆一次。

## 中文场景的三个修正

1. **30 字是参考线**：原版英文 ≤20 词，中文 30 字是 UP 的换算；本质是「一句一事实」
2. **名词一致性比英文场景更值钱**：中文同义词极丰富（"玩家/用户/对方/那哥们"），
   AI 更容易换着叫，而游戏专有名词（BOSS/技能/道具名）被换名对观众伤害最大
3. **第 4 条中文特供**：中文"被"字句和"建议"句是藏主语的两大重灾区，
   英文只有一个被动语态要防
